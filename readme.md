Student Productivity Tracker

About the Project

The Student Productivity Tracker is a web-based application designed to help students manage academic tasks and monitor their progress in one place.

Problem Statement

Students often find it difficult to organize assignments, academic activities and daily tasks. This project provides a centralized platform to manage them efficiently.

Features

- Add new tasks
- View all tasks
- Edit existing tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Dashboard with total, completed and pending task counts
- Progress percentage tracking
- SQLite database storage

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Database: SQLite
- IDE: Visual Studio Code

How to Run the Project

1. Create a virtual environment

python -m venv venv

2. Install dependencies

pip install -r requirements.txt

3. Start the backend

.\venv\Scripts\python.exe -m uvicorn backend.main:app --reload

4. Open the application

Open "sravs.html" in your web browser while the backend is running.
